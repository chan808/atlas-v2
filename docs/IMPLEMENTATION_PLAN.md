# 단계별 구현 계획 초안

기준일: 2026-10-13. 상태: 제안. 이번 세션은 설계·문서만 작성한다.
참조: PRD 및 콘텐츠·데이터·사용자 흐름 계약. 스택·예산의 남은 선택 후 경로를 구체화한다.

## 순서의 원리

각 단계는 사용자가 실제로 할 수 있는 행동과 확인 근거로 끝낸다. 거대한 미래 모듈을 먼저 만들지 않는다. 좁은 작업 계약·독립 검토·실패 검증을 갖춘다. 준비 단계의 fake 결과를 실제 학습 가치의 증거로 쓰지 않는다.

## S0 — 개발 계약과 최소 실행 기반

목표: 선택한 스택에서 계정·데이터·모델 경계를 확인할 수 있고, 첫 기능을 검증하는 명령이 정해진다.
결과: 실행·종료·검증 방법, model-free CI, 저장 migration, 비밀 관리, 한도·작업 기본 계약.
주의: 이 단계만 완료했다고 학습 서비스를 출시하지 않는다.

## S1 — 주제에서 첫 맞춤 설명

목표: 개인이 관심을 입력하고 수준·목표 추천에서 시작하여 첫 설명과 예제를 본다.
포함: 원문 보존, 중요한 최소 질문, 추천 이유·가정, 좁은 실제 AI 연결, 출처·단위·작업 버전, 읽기 가능한 첫 콘텐츠, 실패·재시도.
검증: 처음/경험 있음/일부만/깊게의 사례, 주제 이탈·잘못된 출처·timeout·중복·프로세스 종료.
실사용은 live provider 또는 검토한 실제 자료로 확인한다. 유료 호출은 CI 필수가 아니다.
되돌림: 생성 기능을 끄고 저장한 내용·원문은 조회 가능하게 유지.

## S2 — 조정·이어보기·시각 이해

목표: 더 쉽게/다른 예제/더 깊게/자료·방향 변경 후에도 과거와 현재 위치를 이어간다.
포함: AI·개발에서 의미 있는 제한된 시각 표현, 내용 버전, 개인 활동, PC·안드로이드 재개, 이전 학습 검색.
검증: 설명·그림 일치, 변경 후 stale 결과, 두 기기 사용, 새로고침, 한 단위만 실제 본 경우의 요약.
되돌림: 새 표현을 정적 설명으로 낮추고 이전 콘텐츠 버전 유지.

## S3 — 복습·예습·외국어·기본 음성

목표: 실제 학습한 내용의 요약과 다음 표현·용어를 보고, 짧게 회상하고 적합한 음성을 듣는다.
포함: 외국어의 상황·수준 추천과 변경, 작은 검증 사례, 단위-카드-대본-음성의 참조, 범위·정답 조건, 실제 회상 기록.
검증: 모르는 표현·여러 정답·틀린 카드 수정·화면 없는 설명·TTS 발음·근거 범위.
되돌림: 검증이 안 된 언어 활동이나 음성 생성을 끄고 텍스트와 기존 자료 유지.

## S4 — offline 이동 묶음과 동기화

목표: 안드로이드 비행기 모드에서 준비한 요약·암기·음성을 사용하고 돌아와 중복 없이 기록을 반영한다.
포함: 다운로드 manifest·파일 검증, Service Worker·로컬 저장·outbox, 부분 다운로드·quota/eviction 상태, 개인 계정 경계, 재생·seek·복귀.
검증: 목표폰 실제 실험. offline 재시작·잠금화면·다른 앱·연결 재개·두 번 sync·계정 전환.
되돌림: 문제가 생긴 caching을 비활성화하고 재다운로드/안전한 파일 제공. offline 필수 요구를 충족하지 못하면 초기 개인 사용 완료라고 표시하지 않음.

S1–S4가 첫 개인 사용의 완결 루프 후보다. 한 번에 네 단계를 구현하지 않는다. 외국어의 초기 품질 검증 사례와 어떤 표현을 S2/S3에서 제공할지는 세부 계약으로 정한다.

## S5 — 재사용 템플릿과 주제 연결

목표: 반복 주제에서 검토한 템플릿을 맞춰 쓰거나 새로 시작하고, 과거의 관련 개념으로 이동한다.
포함: 템플릿 메타데이터·검토·버전·개인 변형, 이유가 있는 개념 연결.
검증: 잘못된 수준의 템플릿 추천, 사용자 새 생성, 개인 내용 유출 방지, 오래된 출처, 실제 비용·수정 횟수.
순서 조정 가능: 검토한 작은 템플릿이 S1부터 실제 품질을 높이면 먼저 사용해도 된다. 카탈로그 자체가 목표가 아님.

## S6 — 타인 초대와 자료 공유

목표: 허용한 사람이 특정 학습 자료를 보고 자신의 기록으로 사용한다.
포함: 소유권·공유권한·snapshot·개인 진도 분리·삭제·철회.
검증: 다른 사람 ID 접근, private 출처, 재생성 후 공유·댓글, 자신의 진행이 상대 자료를 덮어쓰지 않음.

## S7 — 같은 페이지 소통

목표: 같은 버전·위치·시각 상태를 보며 질문과 설명을 주고받는다.
실시간 대화와 공동 편집 중 지원할 행동을 먼저 사용자와 결정한다.
검증: 재연결·권한 회수·내용 버전·기기 동시 변경.
새 기능이 실제 함께 공부에 도움이 되는지 확인한다.

## 각 구현 인계에 필요한 것

변하는 사용자 행동, 변경 파일·데이터, 보존 조건, timeout·중복·동시·부분 실패, 실행할 검사와 실제 결과, 롤백·제거 방법. 문서를 따라도 사용자 결과가 바뀌면 먼저 요구를 다시 확인한다.
