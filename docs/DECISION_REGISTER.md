# 결정·제안·검증 대기 등록부

기준일: 2026-10-13
권위: 사용자 원문과 명시적 답변. 문서가 존재한다는 이유로 승인 상태가 바뀌지 않는다.

## 확정된 방향

- 제품 자체의 학습 가치가 목적. 개발 실력 향상 목표 제거.
- AI·개발과 외국어 우선. 독립 수학은 보류 가능.
- 수준·목표에 맞춘 AI 제안과 추천 선택, 언제든 방향·자료 변경.
- 선택적 인기 주제 템플릿, 템플릿이 있어도 새 생성 가능.
- 본 내용 요약·다음 용어/표현 예습·암기·적합한 듣기.
- 개인 PC+안드로이드, 같은 기록. 준비 자료 offline 사용, 새 생성 online.
- 초기 본인 한 명, 타인 공유·실시간은 이후.
- 비용은 현재 주요 제약 아님. AWS 또는 개인 노트북, OpenAI API와 필요 시 로컬 모델 고려.
- 초기 입력은 주제·공개 링크·텍스트. PDF·영상·음성 파일 업로드는 후속.
- offline 미전송 기록은 원래 owner 재로그인까지 보관하고 다른 계정에 보이거나 전송하지 않음.
- 이번 세션은 조사·설계·문서화, 구현은 다른 세션.

근거: [Q1–Q7와 원래 요구](discovery/USER_INTENT.md).

## 에이전트 추천·초안

- 계획 승인 없이 시작 가능한 흐름, 중요한 질문만, 선택적 짧은 회상
- 버전 콘텐츠와 개인 이벤트·복습·이동 묶음 분리
- 검토한 renderer의 데이터 기반 시각화
- Android PWA, 단일 서버·관계형 저장소, v1 기반 선별 재사용
- OpenAI를 첫 품질 기준으로 평가, local adapter는 필요할 때
- 자료 접근은 허용된 공개 출처와 사용자 제공 텍스트에서 시작. 지원하지 않는 추출을 완료한 것처럼 표시하지 않음
- 영어와 한국어 설명을 첫 평가 사례로 쓰는 후보. 모든 사용자 언어를 고정하거나 다른 언어의 품질을 보증하는 결정이 아님
- 작은 템플릿은 초기부터 쓸 수 있지만 대형 카탈로그는 실제 반복 수요로 확대

## 구현 착수 때 명시적으로 고정할 기술 선택

스택 추천안의 수용 또는 대안, 인증 방식, 배포와 HTTPS 접근 경로, 모델·음성 profile과 버전, 초기 링크 추출의 지원 타입, schema/API의 정확한 필드·오류, 요청별 시간·사용량·retry 상한.

이는 사용자 핵심 목표를 다시 질문하라는 뜻이 아니다. 위 추천안과 반박 근거를 확인하고 필요한 선택만 좁게 정한다. 공급자·계정·기기 능력을 확인하지 않고 지원·무료·실행 완료라고 쓰지 않는다.

## 실제 사용으로 검증할 가설

맞춤 시작의 부담 감소, 시각화의 이해 도움, 예습 선별의 유용성, 요약으로 빠른 재개, 회상 활동의 지속, 기존 서비스 대비 선호, template의 비용/품질 효과. 문서만으로 효과를 확정하지 않는다.
