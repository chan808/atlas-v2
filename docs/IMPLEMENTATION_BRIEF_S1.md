# 첫 구현 행동 인계 — 주제에서 첫 맞춤 설명

기준일: 2026-10-13. 상태: 추천 계약. 실제 구현·검증 결과 아님.
전제: 추천 스택 검토. 초기 입력은 주제·공개 링크·텍스트, offline 미전송 기록의 원 owner 보존 정책은 확인됐다. S0와 필요한 기반을 먼저 만든다.

## 사용자 행동

사용자가 정리되지 않은 주제를 입력하면 원문이 저장되고 AI가 수준·목표에 맞는 시작점을 추천한다. 추천 또는 사용자가 바꾼 방향으로 첫 짧은 설명·예제와 연결된 출처를 본다. 최초 저장과 별도의 '명확화 시작' 클릭을 사용자에게 필수로 요구하는 v1 흐름을 복제하지 않는다.

처음 아는 정도·배울 깊이를 이미 입력했다면 반복해서 묻지 않는다. 부족하면 추천과 가정을 표시하고 중요한 선택만 제시한다. 모든 사용자에게 같은 질문이나 예제를 반환하는 fake 결과를 실제 AI 맞춤 학습으로 표시하지 않는다.

## 이번 행동의 범위

원문·개인 소유·방향 제안·작업·첫 콘텐츠 버전·출처·실패·재시도. 좁은 AI·개발 예제를 먼저 평가한다. 큰 과목 커리큘럼·오프라인·실시간·전체 템플릿 카탈로그는 이 행동에 같이 구현하지 않는다. 검토한 작은 템플릿은 실제 자료로 사용할 수 있고 fresh 생성 경로를 막지 않는다.

## 화면

입력 → 준비 상태 → 추천과 이유/수준 가정 → 필요한 선택 → 첫 설명과 예제 → 출처 확인·더 쉽게/다른 예제의 다음 행동 후보.

주제가 모호하더라도 원문은 남는다. provider 실패·근거 부족은 안전한 오류와 같은 작업 재시도/방향 수정으로 이어진다. fake/검토 예시/live 생성의 성격을 구분한다.

## 데이터와 transaction

짧은 transaction에서 인증된 소유자·원문·request key·초기 작업을 저장한다. 외부 모델/출처 호출은 밖에서 한다. 결과 검증 후 현재 attempt/lease token·대상 버전·취소 상태를 확인하고 결과를 적용한다.

같은 키·동일 내용은 같은 생성 결과/job 참조를 반환한다. 다른 내용의 키 재사용은 충돌이다. raw 저장은 성공했고 생성이 실패한 경우 입력을 다시 저장할 필요가 없게 한다. 응답 유실 뒤 재시도가 새 콘텐츠·과금을 무제한 만들지 않는다.

## 생성 결과

direction proposal에는 사용자 사실·추정·추천·가정과 이유가 구분된다. 첫 단위는 목적·블록·예제·출처 위치·버전·검증 결과를 가진다. 형태가 맞는 것과 내용이 참이라는 것을 구분한다. refusal·미완료·틀린 참조·unsupported 주제를 처리한다.

## 파일 후보

선택 스택의 API·웹 앱, 학습 공간/방향/생성 작업/콘텐츠의 migration과 저장, provider adapter, schema, controller·client·주제 입력/준비/첫 설명 화면, HTTP·transaction·UI 테스트, verify 스크립트, 해당 change brief.

v1 기반을 가져올 경우 원문 보존·UTC Clock·Flyway·저장/테스트 방식을 참고한다. 기존 inquiry의 고정 질문·CAPTURED→CLARIFYING·Brief 승인 도메인을 새 학습 흐름의 권위로 사용하지 않는다.

## 필수 검사

- Unicode·공백 원문 보존, 빈 입력·길이 제한의 동일성
- 모르는 사용자·경험 있는 사용자·얕은/깊은 목표 fixture
- 생성/재시도/키 충돌/프로세스 종료/취소/옛 worker 결과
- owner와 다른 계정/인증 없는 ID 접근
- 출처 없는 주장·무관한 인용·invalid schema·refusal·미완료
- 실패해도 원문과 이미 준비한 결과 보존
- 키보드·모바일·라벨·오류·준비 상태
- CI paid model/key 없이 검증. 제한된 live 사례의 내용·지연·usage는 따로 기록

## 되돌림

새 생성 adapter를 비활성화하고 원문·검토한 기존 콘텐츠 조회를 남긴다. migration을 무조건 삭제해서 데이터를 잃지 않는다. 오류·지원 범위·미검증 사항을 README와 change record에 기록한다.

## 완료 증거

사용자가 첫 설명을 실제 볼 수 있고 위 검사가 실행됐으며, live 생성이나 검토된 실제 자료로 첫 학습 경험을 확인한다. compile·fake 테스트 통과만으로 개인화 학습의 가치를 증명했다고 쓰지 않는다.
