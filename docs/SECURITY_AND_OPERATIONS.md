# 보안·비용·운영 설계 초안

기준일: 2026-10-13. 상태: 정책·기술 제안. 비용은 핵심 제약이 아니며 AWS/개인 노트북을 고려한다. 인증·실제 배포 구성은 구현 단계에서 확인한다.

## 개인 사용

PC와 휴대폰이 원격 서비스의 같은 기록에 접근한다면 초기 한 사람이라도 인증·소유권 검사를 구현한다. 다른 사람 가입은 후속 단계다. 외부에 연결되는 API를 ID만 아는 누구나 읽게 만드는 local-only 가정을 사용하지 않는다.

모델·DB·파일 자격증명은 서버에만 둔다. 원문·파일·회상 답변·프롬프트·생성 응답을 일반 로그에 기록하지 않는다. 오류는 안전한 코드·작업 ID·시간·공급자 상태 등으로 조사할 수 있게 남긴다.

## 출처와 파일

외부 자료를 명령으로 실행하지 않는다. 출처 조회의 URL·redirect·응답 크기·시간·지원 타입을 제한하고 내부 주소·로컬 파일·비공개 endpoint에 접근하는 요청을 막는다.

초기 입력은 주제·공개 링크·붙여넣은 텍스트다. PDF·영상·음성 파일 업로드는 후속이다. 읽지 못한 링크·추출하지 않은 영상/PDF를 전체 처리한 것으로 표시하지 않는다. 파일 추가는 필요한 단계에서 형식·크기·추출·오류·보관 계약을 먼저 확정한다. 자료 접근권한을 출처 검색으로 우회하지 않는다.

## 렌더링

AI 텍스트는 안전한 콘텐츠 형식으로 렌더링한다. 임의 HTML/JS·외부 script·기기 권한을 앱 권한으로 실행하지 않는다. 시각화 입력은 스키마·범위·참조·규칙을 검증한다.

## 비용 한도

사용자는 비용을 현재 주요 제약으로 보지 않으며 OpenAI API 자원이 있다고 답했다. 고정 월 상한은 선택하지 않았다. 요청별 유한한 시간·입출력·검색·retry 설정과 사용량 표시를 기본으로 제안한다. 사용자가 비용 한도를 설정하면 병렬 예약과 실행이 그 한도를 넘지 않게 한다. 모든 정상 생성에 반복 승인을 강제하는 흐름은 추천하지 않는다.

예상 비용은 실제 공급자 가격·환율·사용량을 기록해서 계산해야 한다. 토큰 캐시·템플릿·요약 재사용의 절감은 측정한다. 사용자가 설정한 한도에 도달하면 이미 받은 자료는 계속 사용하고 새 유료 생성의 가능한 대안을 알려준다. 유료 실행을 무료라고 표시하지 않는다.

## offline 개인 자료

장치에 저장된 사본은 그 기기를 사용하는 사람에게 노출될 수 있다. 다운로드 범위·크기·삭제를 사용자에게 보여준다. 로그아웃·계정 변경 시 미전송 outbox는 원래 owner에 묶어 보관하고 자동 삭제하지 않는다. 다른 owner의 화면·동기화에는 포함하지 않으며 원래 owner 재인증 후 이어 보낸다. 로그아웃 때 일반 콘텐츠 cache·메모리·재생 정보와 미전송 기록의 보관을 구분한다. 장치 저장소가 사용자가 직접 삭제되면 복구를 보증하지 않는다.

기기에서 저장소가 지워질 수 있으므로 재다운로드 경로를 둔다. offline 사본의 서버 측 즉시 철회를 보증하지 않는다. 초기 개인 사용의 보관·로그아웃 동작과 후속 공유 정책을 구분한다.

## 후속 공유

공유한 콘텐츠 버전, 출처의 공개 가능 범위, 개인 입력·메모·답변·진도를 명시적으로 구분한다. 댓글은 콘텐츠 버전과 블록을 가리킨다. 공유 철회와 이미 다운로드한 사본의 한계를 설명한다. 공동 편집과 현재 위치 동기화는 별도 권한·동시성 계약을 가진다.

## 운영

배포 전에 backup·restore, schema migration·이전 앱 호환, 롤백·실패 작업 회수·파일 정리·사용량 확인을 검증한다. 개인 사용 규모라도 데이터 유실이나 비용 폭증을 정상 동작으로 취급하지 않는다.

지원 지표는 첫 내용까지의 지연, 생성·검증 실패, 재개 성공, offline 파일 누락, sync 중복·실패, 모델·음성 비용이다. 학습 효과와 운영 지표는 다르다.

## 아직 필요한 선택

원격 배포·인증 방식의 실행 설정, 장치 저장과 복원 키 관리, 모델에 보낼 개인 자료의 고지·전송 범위. 월 고정 예산은 요청하지 않았으며 필요하면 사용자가 설정한다. 이 문서는 해당 선택을 확정한 것으로 쓰지 않는다.


정상 종료와 로그아웃의 경계: 해당 owner로 로그인해 준비한 자료는 앱을 닫고 비행기 모드에서 다시 열어도 사용할 수 있어야 한다. 명시적 로그아웃·계정 변경은 모든 탭의 key·콘텐츠/재생 접근 상태를 제거한다. 암호화해 보관한 미전송 기록의 복원과 sync는 원 owner의 online 재인증 뒤 수행한다. 브라우저 저장소 자체가 삭제된 경우는 정상 종료와 다르다.
