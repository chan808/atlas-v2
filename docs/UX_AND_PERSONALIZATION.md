# 사용자 흐름과 개인화 계약 초안

기준일: 2026-10-13. 상태: 설계 제안.
사용자에게 보이는 제어와 의미를 규정한다. 화면 모양·단원 길이는 실사용에서 조정한다.

## 시작

자유롭게 주제를 적거나 이전 학습을 고른다. '처음 듣는다/조금 안다/써봤다/모르겠다'와 '가볍게 이해/직접 활용/깊게 배우기'는 추천 선택 후보다. 사용자가 수준과 목표를 이미 썼으면 같은 것을 다시 묻지 않는다.

AI는 추천 시작점·이유·가정을 보여준다. 잘 모르겠으면 추천으로 시작하고 진행 중 바꿀 수 있게 하는 것이 기본 제안이다. 필요한 최소 수준의 예제로 확인할 수 있지만 시험 통과를 학습 진입 조건으로 두지 않는다.

## 첫 설명

하나의 질문·사례·개념을 설명한다. 필요한 용어를 문맥에서 열어 보고, 예제와 적합한 시각 표현을 함께 본다. 출처는 주장과 연결된 위치에서 확인한다. 생성이 오래 걸릴 때는 상태와 준비된 부분을 보여주되 검증 전 내용을 완성된 설명으로 가장하지 않는다.

## 학습 중 조정

- 더 쉽게: 같은 목적의 설명과 예제를 조절한다.
- 다른 예제: 원리를 유지하며 맥락을 바꾼다.
- 더 깊게: 전제·예외·세부 계산으로 내려간다.
- 모르는 용어: 현재 위치를 유지한 작은 설명을 연다.
- 방향 변경: 바뀐 목표·다음 경로와 영향 범위를 보여준다.
- 자료 변경: 새 자료의 역할과 대체·추가 범위를 보여준다.

한 문장 설명을 다시 받는 것과 경로 전체 재생성을 같은 버튼으로 숨기지 않는다. 내용 변경은 새 버전을 만들고 이전 위치·기록은 남기는 것이 추천이다. 이후 단계만 바꾸는 기본안과 처음부터 다시 시작하는 선택을 구분한다.

## 템플릿 선택

추천 템플릿의 대상·수준·범위·검토일·출처를 보여준다. 바로 사용, 맞춰서 사용, 새로 만들기를 구분한다. 템플릿 사용이 사용자의 개인 목표를 덮어쓰지 않는다. 새로 만들기에는 생성 대기와 예상 비용의 차이를 알려준다. 새 생성은 현재 목표·맥락을 확인/수정한 뒤 기존 템플릿의 경로·단원 재사용을 건너뛰는 독립 생성 작업과 분기다. 기존 기록은 남긴다. 같은 작업의 재시도는 새 분기를 중복 생성하지 않는다. 출처·renderer 재사용은 가능하며 문장이 반드시 달라진다고 보증하지 않는다.

## 재개와 이력

이어보기 위치와 노출·재생 범위를 구분한다. 블록 ID+콘텐츠 버전의 화면 노출, 사용자 읽음 표시, 실제 오디오 재생 구간, 회상 시도를 따로 기록한다. 문서 열기·렌더링·배경 탭·스크롤 끝·오디오 seek만으로 전체를 공부했다고 처리하지 않는다. 노출과 재생도 주의·이해를 보증하지 않는다. 마지막 지점, 그때의 질문과 목표, 관찰한 범위에 맞는 요약, 다음 내용을 먼저 제공한다. 생성했지만 열지 않은 단원은 공부한 내용에 포함하지 않는 것이 제안이다. 요약·예습·회상 결과에서 원래 단원으로 이동할 수 있게 한다.

여러 기기에서의 위치는 기록 손실 없이 합친다. 단순히 진행률이 큰 값을 선택하면 다시 복습한 위치를 잃으므로 기기별 마지막 세션과 현재 이어갈 세션을 구분하는 것이 추천이다.

## 이동용 묶음

본 내용 요약, 다음 내용의 핵심 이름·표현, 짧은 회상, 적합한 음성을 미리 준비한다. 사용자가 받을 범위와 예상 크기를 선택한다. '다운로드 완료'는 manifest와 필요한 모든 파일이 검증된 상태다. 미완료·저장 공간 부족·지워짐은 구분하여 표시한다.

오프라인에는 새 AI 생성 버튼이 가능한 것처럼 보이지 않게 한다. 저장된 내용은 읽고 듣고 답할 수 있다. 회상·위치 변경을 장치에 먼저 저장하고 연결 후 동기화한다. 동기화 실패를 성공으로 표시하지 않는다.

로그아웃·계정 변경 시 미전송 outbox는 원래 owner에 묶어 보관하고 자동 삭제하지 않는다. 다른 owner의 화면·동기화에는 포함하지 않으며 원래 owner 재인증 후 이어 보낸다. 로그아웃 때 일반 콘텐츠 cache·메모리·재생 정보와 미전송 기록의 보관을 구분한다. 장치 저장소가 사용자가 직접 삭제되면 복구를 보증하지 않는다.

## 외국어

사용자가 원하는 상황·언어·수준을 입력하거나 추천에서 고른다. 표현을 처음 접하는 장면, 뜻·사용 조건, 예문, 듣기, 짧은 회상을 연결하는 것이 초기 후보다. 발음·말하기 채점은 별도 품질 검증 후 범위로 추가한다. 지원하지 않는 능력을 '외국어 지원'이라는 포괄적 이름으로 숨기지 않는다.

## 공유 — 후속

학습 자료의 특정 버전을 공유하는 방향이 제안이다. 원문·개인 메모·질문·답변·진도는 자동으로 함께 공개하지 않는다. 같은 페이지에서의 대화와 내용 공동 편집은 별도 기능이다. 개인 난이도 조절이 상대의 공통 자료를 덮어쓰지 않아야 한다.

## 피해야 할 흐름

매번 긴 자기소개·목표 설문, 정답을 못 맞히면 다음 설명을 막음, 관련 용어를 모두 먼저 외우게 함, 사용자를 대신한 목표 확정, 방향 변경으로 이전 기록 삭제, 재생 횟수를 숙련도로 표시, 복잡한 노트 정리를 사용자의 필수 작업으로 둠.


정상 종료와 로그아웃의 경계: 해당 owner로 로그인해 준비한 자료는 앱을 닫고 비행기 모드에서 다시 열어도 사용할 수 있어야 한다. 명시적 로그아웃·계정 변경은 모든 탭의 key·콘텐츠/재생 접근 상태를 제거한다. 암호화해 보관한 미전송 기록의 복원과 sync는 원 owner의 online 재인증 뒤 수행한다. 브라우저 저장소 자체가 삭제된 경우는 정상 종료와 다르다.
