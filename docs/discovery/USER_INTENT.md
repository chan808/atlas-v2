## 아직 사용자 결정이 아닌 제안

- 공통 학습 페이지에서 화면 설명·요약·회상·음성을 파생하고, 출처와 버전을 함께 유지한다.
- 원문을 보존하고 필요한 질문만 한다. 계획 승인 자체를 학습 진입의 필수 단계로 두지 않는다.
- 학습 페이지 공유와 개인 학습·복습 기록은 분리한다.
- 제한된 과목별 표현으로 시작하고, 거대한 범용 교육 엔진을 먼저 만들지 않는다.
- 유용한 개인 학습 흐름을 검증한 다음 실시간 소통을 확장한다.

위 항목은 이전 답변의 추천이다. 사용자의 확정 의사로 취급하지 않는다.

## 현재 요약 — 1차 설계의 기준

제품 학습 가치에 집중. 초기 AI·개발/외국어, AI 수준·목표 추천과 지속 조정, 사용자 방향·자료 변경, 선택적 템플릿과 독립 새 생성. 개인 PC+Android, 준비한 이동 자료 offline, 새 생성 online. 주제·공개 링크·텍스트부터 시작. 다른 사람/실시간/파일 업로드는 후속. 고정 월 예산 없음. AWS 또는 개인 노트북·OpenAI API 자원·필요시 local 모델. offline 미전송 기록은 원래 owner 재로그인까지 보존.

추천 기술·조절 값은 DECISION_REGISTER와 ADR에 제안으로 구분한다. 실제 계정·기기·모델 품질·배포 자원은 구현·사용 단계에서 검증한다. 사용자 요구를 새로 추측해서 질문을 처음부터 반복하지 않는다.
