# 화면 구성과 실제 장면의 설계 예시

기준일: 2026-10-13. 제품 코드·실제 생성 결과가 아닌 설계 예시.
규칙: 핵심 제어를 가까이 두고 계획·출처·세부 기록은 필요할 때 연다.

## 홈·재개

궁금한 주제 입력이 중심이다. 공개 링크와 텍스트를 추가할 수 있다.
아래에 '이어서 보기', '이동용 준비 자료', 최근 학습을 배치한다. 거대한 진도 dashboard를 첫 화면으로 강제하지 않는다.

입력 예시: 'RAG가 뭔지 단어만 알고, 왜 쓰는지 알고 싶어.'
추천 예시: '모델이 모든 최신 자료를 알고 있지는 않다는 문제부터 보겠습니다. 구조를 먼저 이해하는 방향을 추천합니다.'
선택: 추천으로 시작 / 목표 바꾸기 / 이미 아는 부분 조정.

예시의 사용자 수준은 실제 사용자의 고정 프로필이 아니다.

## 학습 화면

PC: 작은 경로 목록 + 본문·시각화 + 필요한 때 여는 도움·출처.
Android: 한 단위 본문을 중심으로 하고 도움·경로는 펼치는 패널. 아래에 계속·더 쉽게의 주 행동.

AI 예시 흐름:
질문 → 작은 실패 사례 → 검색한 자료를 답변에 연결하는 구조 → 근거가 틀리거나 오래됐을 때의 한계 → 선택적 예측 질문.
시각 상태는 준비한 예제의 단계·출처 조건과 연결한다. 실제 모델을 실행한 결과처럼 꾸미지 않는다.

도움: 이 용어 / 다른 예제 / 더 깊게 / 방향·자료 바꾸기.
원문·출처를 매번 화면 전체로 강제하지 않되 쉽게 다시 확인할 수 있게 한다.

## 방향과 템플릿

추천 경로의 범위·이유·가정을 먼저 본다.
적합한 템플릿: 그대로 시작 / 내 목표에 맞춰 변형 / 독립 새 생성.
변경: 이후 내용만 조정 / 새 분기로 처음부터. 이전 학습은 보관.

새 생성이 기존 template progress reset과 다름을 문구와 작업에서 보여준다.

## 이동 화면

받은 묶음마다 요약 / 다음 표현·용어 / 짧은 회상 / 듣기.
'이 기기에 준비 완료'와 '서버에는 준비됨'을 구분한다.
인터넷 없이 생성할 수 있는 것처럼 보이지 않게 하고, 미전송 기록 수·sync 상태는 필요할 때 확인한다.

외국어 예시: 회의에서 이해하지 못한 말을 정중하게 다시 요청하기.
뜻과 사용 상황 → 짧은 예문 → 듣기 → 뜻 또는 상황을 보고 표현 떠올리기.
이는 영어 사례 평가 후보이며 사용자 목표 언어·학습 능력을 고정하는 결정은 아니다.

## 이력·관련 주제

제목·공부한 맥락·마지막 위치·본 범위와 회상 기록을 확인하고 해당 콘텐츠 버전으로 돌아간다.
관련 링크에는 이유를 붙인다: '이 주제의 전제', '같은 문제의 다른 방식', '혼동하기 쉬운 차이'.
처음에는 작은 목록으로도 충분하며 graph 시각화 자체를 필수로 만들지 않는다.

## 후속 함께 보기

공유된 고정 버전과 같은 블록에서 질문·댓글·대화를 한다. 공통 페이지와 개인 난이도 변형·개인 진도는 구분한다. 공동 편집은 별도 요구로 결정한다.
