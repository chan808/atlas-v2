# 시각적 이해·개발·AI 학습 서비스 조사

확인일: 2026-10-13 (Asia/Seoul)
근거: 공식 제품 페이지·도움말·공개 강의. 유료 강좌 수강이나 계정 내부 생성 실험은 수행하지 않았다.
적용 범위: AI·개발은 초기 우선 대상. 독립적인 수학 교육과정은 사용자 답변에 따라 후속 대상이다. 수학 서비스는 시각 표현과 협업 원리를 비교하는 참고다.

## 비교 관점

입력 장벽, 설명의 순서, 의미 있는 상호작용, 내용의 저작·검토 방식, 학습 기록, 공유 경계를 비교한다. 업체의 효과·정확도 주장을 독립 검증 결과로 취급하지 않는다.

## Brilliant / Koji

공식 흐름: 과목·Learning Path에서 작은 설명과 시각 문제를 진행한다. 수식 입력과 드래그 등의 조작에 피드백을 주며, Koji는 현재 문제의 맥락에서 도움을 제공한다. 자연어 수학 질문을 기존 강의로 연결하는 기능도 안내한다.

- [Learning Paths](https://brilliant.org/help/features/what-are-learning-paths/)
- [질문에서 적합한 강의 찾기](https://brilliant.org/help/features/ask-koji-a-math-question-and-find-the-right-lesson/)
- [상호작용](https://brilliant.org/help/features/how-do-i-use-interactives-on-brilliant/)
- [Koji](https://brilliant.org/help/features/how-does-koji-work/)

제작 현실: 공식 제작 글은 학습 목표·진행·핵심 깨달음을 사람이 설계하고 AI가 구현과 변형을 돕는다고 설명한다. 생성 문제도 사람의 검토를 거친다. 이 사례는 임의 주제의 고품질 시각 수업을 무검토 자동 생성할 수 있다는 증거가 아니다. [제작 과정](https://blog.brilliant.org/hand-crafted-machine-made/)

Atlas 추론: 조작의 목적을 먼저 정한다. 사용자가 무엇을 바꾸고 어떤 관계를 깨닫는지 없는 시각화는 장식으로 분류한다. 초기에는 검증 가능한 소수의 표현을 잘 만드는 편이 유리하다.

## Khan Academy / Khanmigo

공식 흐름: 영상·글·연습·퀴즈·단원 시험이 연결되고, 해당 문제 체계의 skill 상태가 변한다. Mastery Challenge는 이전 학습 skill을 다시 문제로 확인한다. Khanmigo는 대화로 학습을 돕지만 공식 안전 설명도 잘못된 정보를 줄 수 있다고 명시한다.

- [Mastery의 정의](https://support.khanacademy.org/hc/en-us/articles/115002552631-What-are-Course-and-Unit-Mastery)
- [복습 Challenge](https://support.khanacademy.org/hc/en-us/articles/360037494231-What-are-Mastery-Challenges)
- [AI 안전·한계](https://support.khanacademy.org/hc/en-us/articles/14394814244365-What-safety-features-does-Khanmigo-have)

음성 제약: TTS는 Khanmigo 자기 응답을 읽고 일반 강의 글·연습·시험 전체를 읽지는 않는다. 한국어 지원과 완전 품질 검증 언어는 서로 다르다. [TTS](https://support.khanacademy.org/hc/en-us/articles/23772334788365-Does-Khanmigo-have-a-read-aloud-or-Text-to-speech-feature), [언어 품질](https://support.khanacademy.org/hc/en-us/articles/41626114291469-Which-languages-can-I-use-for-Khanmigo-and-free-teacher-tools)

Atlas 추론: 읽거나 들은 사실과 답을 떠올리거나 적용한 사실을 구분한다. 지원 언어 목록만으로 한국어 교육 품질이 검증됐다고 쓰지 않는다.

## 3Blue1Brown

공개 신경망 강의에서 사례→직관→필요한 수식→다음 장의 설명 흐름을 확인했다. 웹 강의에는 시각 데모, 답 펼치기, 작은 확인 문제, 각주와 다음 개념 연결이 있다. 영상만 제공하는 서비스로 요약하면 부정확하다.

- [신경망 첫 강의](https://www.3blue1brown.com/lessons/neural-networks/)
- [역전파의 미적분](https://www.3blue1brown.com/lessons/backpropagation-calculus/)

Atlas 추론: 대상·색·비유를 설명 과정에서 일관되게 유지하고, 직관과 수식을 연결한다. 이 강의는 저자와 각색자가 있는 저작물이며 같은 품질의 자동 생성 가능성을 입증하지 않는다.

## Desmos / Amplify Classroom

Desmos는 식의 변수에 slider를 연결하여 값 변화와 그래프 변화를 관찰하게 한다. 별도 Classroom 서비스는 현재 Amplify Classroom이다. 수업 공유, 화면별 응답, 진행 맞춤·멈춤, 응답 snapshot과 토론을 제공한다.

- [Sliders and Movable Points](https://help.desmos.com/hc/en-us/articles/202529069-Sliders-and-Movable-Points)
- [Classroom의 현재 구분](https://help.desmos.com/hc/en-us/articles/23421565218573-Amplify-Classroom-formerly-Desmos-Classroom-now-a-part-of-Amplify)
- [Classroom 소개](https://amplify.com/blog/problem-based-learning/introducing-amplify-classroom/)
- [공식 Classroom 기능](https://amplify.com/classroom/)

Atlas 추론: 시각화의 변화가 설명과 동일한 계산·상태에 연결돼야 한다. 실시간 학습은 채팅뿐 아니라 같은 위치·설정·예측을 함께 보는 경험이 될 수 있다. 공동 편집까지 필요한지는 별도 사용자 결정이다.

## GeoGebra

Activity·Book에서 동적 수학 자료를 탐색하고, Lessons로 자료와 응답을 공유한다. 교사는 진행과 답변을 확인하고 토론을 진행할 수 있다. Math Practice는 별도 단계적 풀이 도구다.

- [플랫폼](https://www.geogebra.org/?lang=eng)
- [자료 배정과 실시간 학습](https://help.geogebra.org/hc/en-us/articles/8828154551965-Assign-GeoGebra-Resources)
- [저작 튜토리얼](https://www.geogebra.org/m/deff7B2d)
- [Math Practice](https://help.geogebra.org/hc/en-us/sections/15090209460253-GeoGebra-Practice)

Atlas 추론: 개별 시각 자료를 이어지는 학습 단위로 묶고 탐색과 연습을 구분한다. 커뮤니티에 공개된 자료라는 사실과 내용·교육적 검증은 다르다.

## DataCamp / AI Tutor

공식 자료는 짧은 설명·실습·피드백의 연결, 단계별 실습, 속도와 예제를 조절하는 AI Tutor를 설명한다. 완료한 학습을 바탕으로 복습 문제를 생성하는 기능도 있다. 2026년 공식 설명에는 강사가 정의한 자료 기반의 적응형 학습이 등장한다.

- [현재 AI Tutor](https://www.datacamp.com/learn/ai-tutor)
- [실습 유형](https://instructor-support.datacamp.com/en/articles/2360969-exercise-types)
- [복습 생성](https://support.datacamp.com/hc/en-us/articles/28562143877015-DataCamp-Practice-Reinforce-Your-Learning-with-Hands-On-Exercises)
- [2026 공식 설명](https://www.datacamp.com/resources/webinars/datacamp-quarterly-roadmap-2026-q2)
- [XP와 진행의 정의](https://support.datacamp.com/hc/en-us/articles/34043400793495-Understanding-XP-and-Progress-on-DataCamp)

Atlas 추론: 이미 본 내용의 범위에서 복습을 만들고, 어려울 때 다른 예제·느린 설명을 쉽게 요청한다. 기존 카탈로그에서의 개인화와 임의 주제를 즉석 교육과정으로 만드는 능력을 구분한다. 활동량을 실력으로 환산하지 않는다.

## 요구와 연결

- U02/U13: 첫 설명, 시각적 원리 이해, AI·개발 예제
- U04/U06: 실제 본·들은 범위의 기록과 화면 의존성을 제거한 요약
- U07: 문맥 안에서 다음 개념 연결
- U08/U14: 같은 자료의 공유·토론. 타인 사용의 초기 포함 여부는 미정

## 후속 확인

실제 계정에서 처음 이해 장면까지의 시간, 막힌 부분 해결 비용, 한국어 품질, 학습 뒤 기억, 모바일 사용을 비교해야 한다. 공식 기능 목록만으로 이 결과가 좋다고 결론내리지 않는다.
