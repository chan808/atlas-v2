# 외국어 학습 방식과 학습 연구의 적용 범위

확인일: 2026-10-13 (Asia/Seoul)
상태: 설계 근거. 사용자 선호·교육 효과를 확정하지 않는다.
초기 외국어의 언어와 목표 능력은 인터뷰 중이다.

## 실제 외국어 서비스

Duolingo의 AI Video Call 제작 설명은 수준·대화 목적·혼란 대응·종료를 학습 설계자가 정하는 방식을 소개한다. 대화 모델을 연결하는 것만으로 수준에 맞는 학습 대화가 완성되는 사례는 아니다. [공식 설계 설명](https://blog.duolingo.com/ai-and-video-call/)

Busuu Conversations는 학습한 어휘·문법을 수준에 맞는 상황에 적용하고 이후 피드백을 제공한다. 기능표는 어휘·문법 복습, 발음, 상황 대화 등의 목표를 구분한다. [Conversations](https://www.busuu.com/en/languages/speak-fluently-with-busuu-conversations), [현재 기능표](https://www.busuu.com/en/premium-plans)

Atlas 추론: 읽기·어휘·문법·듣기·발음·말하기 중 무엇을 지원하는지 계약을 정한다. 설명 카드를 번역하거나 TTS를 붙인 사실만으로 외국어 전체를 지원한다고 주장하지 않는다. 실제 언어 능력 향상이나 해당 앱들의 효과를 이 조사에서 검증하지 않았다.

## 사전 학습 — Mayer, Mathias, Wetzell (2002)

기계 장치의 설명 전에 구성 요소를 익히게 한 세 실험에서 전이 과제 성과의 개선을 보고했다. [원 논문](https://pubmed.ncbi.nlm.nih.gov/12240927/)

설계 가설: 바로 다음 설명에 필요한 이름·역할·기호·표현만 작게 준비시킨다.
한계: 모든 과목의 광범위한 선행 암기, 정확한 카드 개수나 소요 시간, 강제 암기 통과 조건을 입증한 연구가 아니다.

## 분절과 속도 조절 — Mayer, Chandler (2001)

학습자가 설명 진행을 조절한 두 실험에서 전이 성과가 개선됐지만 기억 과제의 차이는 확인하지 못했다. [연구 원문](https://tecfa.unige.ch/tecfa/teaching/methodo/Mayer_Chandler01.pdf)

설계 가설: 다시 계획하지 않고 다음 내용을 볼 수 있는 연속성과, 쉬지 않는 자동 재생을 구분한다. 계속·잠깐 멈춤·더 쉽게를 제공하는 방향을 검토한다.
한계: 모든 분야·오디오만의 학습·특정 단원 길이의 효과를 증명하지 않는다.

## 회상과 다시 읽기 — Roediger, Karpicke (2006)

즉시 검사와 지연 검사에서 반복 읽기와 회상 연습의 결과가 다름을 보고했다. [연구자 기관의 원문](https://psychnet.wustl.edu/memory/wp-content/uploads/2018/04/Roediger-Karpicke-2006_PsychSci.pdf)

설계 가설: 짧은 요약은 재개를 돕고, 기억을 유지하려면 답을 먼저 떠올리는 기회도 필요하다.
한계: 듣기·읽기 시간이 길면 이해했다고 판단할 근거가 아니다. 사용자가 받아들이는 질문 방식·빈도는 별도 확인해야 한다.

## 개념도와 회상 — Karpicke, Blunt (2011)

해당 실험에서 회상 연습이 개념도 작성 중심 학습보다 개념 학습 성과에서 유리했다. [원 논문](https://pubmed.ncbi.nlm.nih.gov/21252317/)

설계 가설: 주제 연결 지도는 탐색과 문맥 복원을 돕는다. 지도 이용량을 암기·숙련으로 환산하지 않는다.
한계: 개념도가 무용하거나 모든 수업에서 회상이 항상 우월하다는 일반적 결론은 아니다.

## 간격을 둔 연습 — Cepeda 등 (2006)

언어적 회상 과제의 메타분석은 반복 간격과 최종 검사까지의 시간이 함께 기억에 영향을 준다고 보고한다. [원 논문](https://pubmed.ncbi.nlm.nih.gov/16719566/)

설계 가설: 같은 내용을 몰아서 반복하는 대신 이후 회상 기회를 예약하고 실제 응답으로 조절한다.
한계: 개인별 최적 일정, 앱의 기억 예측 정확도, 모든 종류의 학습에 같은 일정이 적합함을 입증하지 않는다.

## 수행과 학습의 차이 — Bjork 연구실

연구실은 회상·간격·교차 연습과 당장의 수행/장기 학습 차이를 설명한다. 기법들을 섞는 효과도 단순 합산으로 취급하면 안 된다. [연구실 설명](https://bjorklab.psych.ucla.edu/research/)

설계 가설: 적은 준비로 시작하면서도 도움이 되는 짧은 회상 활동은 허용할 수 있다. 사용자에게 계획 승인·정리·복잡한 조작을 강제하는 마찰과 회상 활동은 다르다.

## 콘텐츠 평가에서 구분할 것

- 생성됨: 자료가 존재함
- 열람·청취됨: 사용자가 해당 범위에 노출됨
- 시도됨: 사용자가 문제·회상에 참여함
- 회상됨: 어떤 조건·시점의 답변 결과가 있음
- 적용됨: 새 사례에 사용한 기록이 있음

위 구분은 설계 제안이다. 수치·등급의 표시 여부와 지원하는 검사의 종류는 아직 확정되지 않았다. 개인 사용 파일럿은 사용자 선호와 결함을 찾는 근거이며 교육 효과를 일반화하는 실험이 아니다.
