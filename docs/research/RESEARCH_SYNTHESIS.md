# 조사 종합과 v2에서 검증할 가설

기준일: 2026-10-13 (Asia/Seoul)
상태: 조사에서 나온 제안. 확정 PRD·기술 결정 아님.
세부 근거: [시각·개발](INTERACTIVE_AND_TECH_LEARNING.md), [정리·복습·음성](STUDY_TOOLS_AND_AUDIO.md), [언어·학습 연구](LANGUAGE_AND_LEARNING_SCIENCE.md).

## 핵심 발견

1. 요약·카드·퀴즈·음성·순차 학습·AI 설명은 이미 여러 실제 서비스가 제공한다. Notebook의 출처 검색, Quizlet의 주제 카드 초안, StudyFetch의 Mini Apps까지 비교에 포함해야 한다.
2. 검토된 사람이 저작한 정교한 수업과, 임의 주제에서 자동 생성한 자료는 같은 품질 근거를 가지지 않는다.
3. 한국어·목표 외국어, 모바일·오프라인·화면꺼짐, 기록·개인 진도·공유는 각각 별도 확인할 계약이다.
4. 학습자가 목표와 자료를 정리하는 부담을 줄이는 것이 중요하다. 그 부담을 방대한 노트 관리나 계획 승인으로 되돌려서는 안 된다.
5. 첫 설계 대상은 사용자 답변에 따라 AI·개발과 외국어다. 독립 수학 학습은 보류 가능한 범위이며 초기 포함 여부는 아직 확정하지 않았다.

## 차별화 후보 — 아직 검증하지 않은 가설

아무 관심 주제를 입력하는 출발점에서, 적합한 근거를 선별하고 이해에 필요한 시각 표현을 이어지는 설명으로 제공하며, 실제 본 내용을 요약·예습·암기·듣기·장기 이력으로 재사용하면 사용자의 부담이 줄어들 수 있다.

이 조합이 경쟁 서비스에 없다는 주장이 아니다. 실제 사용자 사례에서 더 편하고 내용이 더 믿을 만한지를 비교해야 한다.

## 기존 도구 사용도 비교 대상이다

개발 실력 향상이 목표에서 제거됐으므로 새 제품을 만드는 행위 자체가 성공이 될 수 없다. 가장 맞는 기존 도구를 사용하거나 조합하는 방법을 기준선으로 비교한다. 기존 서비스보다 이 사용자에게 더 나은 경험을 제공하지 못하면 지원 범위나 제품 접근을 바꾸는 것이 적절하다.

## 제안하는 첫 가치 루프

주제 입력 → 필요할 때만 수준·방향 확인 → 첫 짧은 설명과 적합한 시각 표현 → 더 쉽게/다른 예제/더 깊게/계속 → 실제 본 범위와 위치 저장 → 재방문 요약 → 필요한 다음 용어·표현과 선택적 회상

외국어 목표, 입력 자료, 질문 허용 방식, 자동 생성·재생 범위, 모바일·오프라인 요구는 사용자 답변을 받아 구체화한다.

## 품질과 부담의 절충

- 빠른 시작을 위해 검증 없이 맞는 척하는 설명을 내보내지 않는다. 근거 부족이면 제한을 알리고 좁은 예제를 제안하는 방식이 후보이다.
- 시각 표현의 계산·상태는 설명과 일치해야 한다. 지원하지 않는 조작형 콘텐츠를 임의 코드로 가장하지 않는다.
- 복습은 필수 관문인지 선택 보조인지 사용자 결정이 필요하다.
- 개인 원문·회사 맥락·회상 답변이 공유 자료에 자동 포함되는 방식은 별도 동의와 명확한 범위를 요구하는 후보 정책이다.
- 생성 결과가 아니라 실제 사용 범위를 재개·복습의 기준으로 삼는 방향을 검토한다.

## 실패·축소 기준 후보

- 첫 설명을 보기 전 사용자가 다시 공부 계획을 짜야 하면 진입 흐름을 수정한다.
- 시각 자료가 이해를 돕지 않거나 결과가 틀리면 해당 표현을 제외·수정한다.
- 예습 목록이 긴 숙제로 느껴지면 선별 범위와 노출을 줄인다.
- 요약을 본 뒤에도 어디서 이어갈지 모르면 기록·재개 흐름을 수정한다.
- 기존 도구보다 선호되지 않으면 기능 수를 늘리기 전에 지원 사례와 차별화 가설을 재검토한다.
- 같은 자료를 공유해도 실제 논의가 생기지 않으면 실시간 공동 편집을 앞당기지 않는다.

위 기준은 제안이며 수치·기간·최종 우선순위는 아직 사용자와 합의하지 않았다.

## 남은 조사

사용자가 고른 실제 사례에 맞춰 최초 사용 절차·내용 오류·한국어 품질·이동 중 재개를 직접 비교한다. 추가 조사는 수량을 늘리는 목적이 아니라 남은 설계 결정을 바꾸는 근거를 찾는 목적으로 한다.
